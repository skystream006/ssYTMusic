## Native state and password workflow

- [MainActivity.isKidModeEnabled](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1084) derives enabled state from **verifier presence**, not a second boolean. [KidModePassword.create/matches/derive](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/KidModePassword.java#L21) stores a salted PBKDF2 verifier, rejects empty/malformed values, and compares derived bytes with `MessageDigest.isEqual`. Do not store the plaintext password or expose a credential JavaScript bridge.
- [MainActivity.showKidModePasswordDialog](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1399) validates empty/mismatched input before entering busy state, clears input, hides the keyboard, and submits derivation/verification to `passwordExecutor`, **off the UI thread**. It clears the copied secret afterward. [setKidModePasswordBusy](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1524) hides the form/buttons and prevents dismissal/resubmission while work runs; failures restore the same dialog.
- Persist successful changes only. A failed credential check does not edit preferences; a failed commit restores previous in-memory verifier state and does not apply the transition. Only after successful persistence update the switch/Home overlay/script, stop loading/media, clear history and verified playlist state, navigate to the appropriate home, and dismiss. Ignore completion for a finishing/destroyed activity or dismissed dialog.
- [updateKidModeScript](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1166) maintains the Home overlay and the origin-scoped document-start registration. Enabling requires `DOCUMENT_START_SCRIPT`; existing enabled state without a handler must fail closed. [loadUrl](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1819) loads `about:blank` when enforcement cannot be installed; [MusicWebViewClient.handleUrl](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L2290) retains the same boundary for page navigation. A late page injection is not a substitute for this gate.

## URL admission is not playback authorization

- [KidModeNavigation.isAllowed](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/KidModeNavigation.java#L13) admits only trusted HTTPS library and explicit playlist/watch forms. It rejects radio identifiers, standalone watch links, malformed/encoded paths, credentials, and untrusted origins/ports. This is only the native URL gate; it does **not** establish track membership.
- [kid_mode.js: allowed/member/capturePlaylist](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/assets/kid_mode.js#L75) authorizes watch links only against the selected playlist and verified IDs. [capturePlaylist](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/assets/kid_mode.js#L132) learns membership from visible playlist-detail rows bound to that playlist, never suggestions, player queue, or automix. Retain verified IDs as rows virtualize; changing playlists invalidates the prior selection.
- [canPlay/enforcePlayback](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/assets/kid_mode.js#L179) checks the player's **actual** video and playlist, not merely the watch URL. Two different verified member IDs can coexist during a legitimate transition. Native notification Play still passes through the guarded media `play`; [canSkip](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/assets/kid_mode.js#L228) permits only a verified adjacent queue member. A URL with a permitted `list` never authorizes an arbitrary track, radio, or standalone playback.
- [session restoration/reset](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/assets/kid_mode.js#L41) preserves membership only for an already verified watch reload. Reset clears selection/storage and stops playback. Session membership is not a password or an independent authorization source.
- [apply/capture-phase click guards/history hooks/MutationObserver](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/assets/kid_mode.js#L308) reassert policy across SPA navigation and actual media changes without observer loops. Hide discovery/Related/automix and disable autoplay; programmatic clicks must also be blocked. Preserve the logo visibly but inert/disabled—do not hide it or turn its click into navigation. The separate native Home action leads to Library.
- [activity_main.xml: kid_mode_home_button](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/res/layout/activity_main.xml#L51) is the accessible upper-left overlay; [dialog_preferences.xml: kid_mode_switch](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/res/layout/dialog_preferences.xml#L208) is the native setting. Keep their policy wiring here, not in presentation logic.

## Boundaries

Consult [playback](/home/runner/work/ssYTMusic/ssYTMusic/Skills/playback/SKILL.md) when media commands, native/page gestures, compact controls, thumbnails, reloads, or resume handling interact with enforcement. Playback owns those mechanisms; this domain owns whether the resulting action is allowed. Consult [webview-shell](/home/runner/work/ssYTMusic/ssYTMusic/Skills/webview-shell/SKILL.md) when changing shared Home/history routing or native settings/overlay composition. Generic themes, logo artwork, network integrations, and build changes are excluded; consult [repo-router](/home/runner/work/ssYTMusic/ssYTMusic/Skills/repo-router/SKILL.md) only if needed. Do not reinterpret site “kids” metadata as authorization.

## Targeted device checks

- Password changes: check empty/mismatched/wrong credentials, visible progress, hidden keyboard, blocked resubmission/dismissal, failure recovery, successful persistence across restart, and Home overlay state. Check unsupported document-start capability refuses enabling and already-enabled navigation stays fail closed.
- Policy changes: open a playlist detail, play verified rows, and transition between verified tracks. Try forged playlist/watch combinations, standalone/radio links, discovery/Related controls, queue suggestions, and notification/swipe Next beyond verified membership. None may authorize forbidden playback.
- Navigation/state changes: exercise SPA/history/deep links, reload a verified watch, change playlist, enable/unlock, and return Home. Verify old membership/history cannot leak, autoplay stays off, logo remains visible/inert, and the native Home overlay remains usable.
