## Entry points and invariants

- [MainActivity.BACKGROUND_PLAYBACK_SCRIPT](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L420) reports playing state, metadata, location, and position through the native bridge. Buffering without current media data is still active when media is neither paused nor ended. Real pause/end remains inactive; reporting must not force `.play()`. Keep coalesced reports and the explicit immediate-report hook.
- [MainActivity.configureWebView](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1048), [setPlaybackBridgeEnabled](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1851), and [PlaybackBridge](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L2088) own installation and reporting. Retain playback-origin scoping; the bridge is removed outside playback scope. Document-start support gates early injection, with background-script fallback in [injectPageScripts](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1715).
- [MainActivity.onPause](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L953) establishes the foreground service **while the activity is still visible**, before `super.onPause()`, not in `onStop`. [startPlaybackKeepAliveService](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1864) uses ordinary service starts for subsequent state updates; they must not create another foreground-start obligation.
- [PlaybackKeepAliveService.onStartCommand](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/PlaybackKeepAliveService.java#L82) mirrors state into notification/media session. **WebView owns audio output and audio focus**; this service must not request focus. Wake-lock ownership follows playing state. [setPlaying](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/PlaybackKeepAliveService.java#L319) retains paused controls; [stopPlayback](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/PlaybackKeepAliveService.java#L142) removes the notification and stops the service.
- [MainActivity.updatePlaybackService](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L2068) ignores duplicate state reports and synchronizes pause without removing an existing notification. [applyMediaCommand](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1996) sends actions to existing page media/controls. Preserve the start-token check so stale service-stop notices cannot invalidate a newer service instance.
- [PlaybackWebView.onWindowVisibilityChanged](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/PlaybackWebView.java#L198) suppresses native hidden-window suspension, including while paused. The background script separately spoofs page visibility and suppresses visibility events. Therefore [MainActivity.onResume](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L931) refreshes existing presentation controllers from native lifecycle; do not depend on page visibility events or reload/reinject to recover geometry.
- [MainActivity.SONG_REFRESH_SCRIPT](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L170) and [SongRefreshCounter.songStarted/songEnded/reset](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/SongRefreshCounter.java#L8) track stable main-player video IDs, not URLs or buffering. The sixth uninteracted song start triggers refresh. **Reset clears the count but retains the last ID**; only matching end clears that identity. Native input and real page input reset counting; service lifecycle is not user input. The native background check reuses page song detection rather than visibility-gated page timers.
- [Preferences.playbackIdentityUrl/buildPersistedPlaybackUrl/isSamePlaybackItem](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/Preferences.java#L42) and [MainActivity.restorePlaybackPosition](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/MainActivity.java#L1958) scope saved progress to the same video/playlist identity, ignoring timestamps. [Urls.sanitizeHttpsThumbnailUrl](/home/runner/work/ssYTMusic/ssYTMusic/app/src/main/java/com/skystream/ssmusic/Urls.java#L116) constrains notification artwork; URL helper tests are not network-download tests.

## Boundaries

Consult [kid-mode](/home/runner/work/ssYTMusic/ssYTMusic/Skills/kid-mode/SKILL.md) before changing transport or route handling: a playable URL is not playlist membership authorization. Consult [presentation](/home/runner/work/ssYTMusic/ssYTMusic/Skills/playback/references/presentation.md) only when foreground recovery, gestures, compact state, or video artwork is affected. Consult [webview-shell](/home/runner/work/ssYTMusic/ssYTMusic/Skills/webview-shell/SKILL.md) when bridge scope crosses shared URL/account-navigation boundaries. General settings, branding, ad filtering, and build/integration behavior are excluded; route them through [repo-router](/home/runner/work/ssYTMusic/ssYTMusic/Skills/repo-router/SKILL.md).

## Targeted device checks

- For lifecycle changes: play, buffer, background, lock, pause from notification, and resume while hidden. Pausing retains transport controls; explicit stop removes them. Check notification metadata/seek and audio-focus handoff with another app.
- For song tracking: advance six songs without interaction, repeat an ended track, and interact mid-sequence. Verify foreground/background transitions do not themselves reset the counter or recount the current song.
- For persistence: reopen the same item and then a different video/playlist; stale progress must not leak. For resume hooks, return from a hidden/rotated compact player without a reload or playback restart.
